# Calendar spaceflight marks

These marks identify launch operators and the International Space Station in event
coverage. They are displayed intact with `object-contain` on the calendar's
dark surface, with no white backing plate. The web UI renders the dark SpaceX,
Blue Origin, and ESA wordmarks in white using CSS brightness/inversion;
Arianespace retains its original colors. ISS uses a simple white text wordmark
created for stars.guide; it is not the official NASA program emblem.
No affiliation or endorsement is implied.

Original provider marks verified through Commons image metadata on 2026-10-12.
The archived ISS emblem uses the provider's 320px thumbnail. The current ISS
wordmark has outlined glyphs so it needs no font download or platform fonts. The company
marks may still be trademarks. Providers without a verified asset retain their
operator name and the existing event glyph. Schedule coverage is independent
of this presentation registry and includes all providers on the bounded LL2 page.
